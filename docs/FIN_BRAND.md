# Fin identity and login

Fin is the product identity for the DropX Finance workspace. The corporate logo at `public/dropx-logo.png` is unchanged. The Fin mark accompanies it; it does not replace the company mark.

## Design

Charcoal, ivory and restrained amber. Editorial typography and a ledger-inspired workflow describe approvals, payment processing and reconciliation without invented metrics or transaction records. Mobile puts sign-in before the supporting narrative.

The generated F symbol represents aligned ledger bands and a reconciled entry. Generated with the imagegen skill in generate mode, without a parent-brand reference. Brief: premium geometric capital F, ledger-like bands, deliberate gap and amber square; charcoal #252B36 and amber #F5A800; transparent background; no currency symbols, chart arrows, enclosing badge or text. Selected source: exec-79926382-c833-4db5-8b62-f45f42ad9459.png. Delivery assets are trimmed/resized PNG derivatives; the original generation is retained outside the repository.

## Scope and safeguards

- Finance-only login component and metadata selected by existing host detection.
- Existing Google server action, safe return-path checks, session handling and role checks unchanged.
- Finance dashboard sidebar and mobile header use the product lockup. Financial queries, approvals and payouts unchanged.
- Other portals retain their existing branding and manifest.
- Finance manifest is a home-screen identity, not a claim of offline support.
- Parent logo integrity verified against production baseline 80880ce6b982a9919f6ba6c43ba8df1b3e8429e9.
