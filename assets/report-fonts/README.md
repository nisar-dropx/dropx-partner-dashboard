# Review report fonts

Noto Sans, Noto Sans Malayalam, Telugu, Devanagari, Tamil and Kannada regular fonts are bundled for server-side PDF generation. Each font is used only when the report contains the corresponding script. No external font requests are made during a report download.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf
